# House Price Prediction

## Project Overview
A Machine Learning project that predicts house prices using housing-related features such as location, area, number of rooms, and amenities.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Machine Learning

## Project Workflow
1. Data cleaning and preprocessing.
2. Handling missing values and outliers.
3. Exploratory Data Analysis (EDA).
4. Comparing six regression models.
5. Hyperparameter tuning using GridSearchCV.
6. Model evaluation.

## Model Performance
- Best Model: Gradient Boosting Regressor
- R² Score: 0.87
- Mean Absolute Error (MAE): Approximately $17K

## Objective
To build a regression model that estimates house prices based on relevant property features.
